# Security

## Report a problem

Report a security problem through [GitHub Issues](https://github.com/GoldenSample/audit-lock/issues). If the details could help an attacker, open an issue that says only "security contact" and keep the details out of it: you get a private channel in that issue.

## Supported versions

Only the latest release gets fixes.

## Scope

The scripts in `scripts/`, the example configs in `assets/`, and the instructions in `SKILL.md` and `references/`.
